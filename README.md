# Dalbran Distribuidora - Sistema Comercial

Sistema web rápido, responsivo e offline-first para geração de orçamentos e controle de produtos da Dalbran Distribuidora.

## Instalação e Execução

### Pré-requisitos
* Node.js v18+
* Conta no GitHub
* Conta no Firebase

### Passo a Passo Local
1. Clone o repositório: `git clone https://github.com/SEU_USUARIO/dalbran-distribuidora.git`
2. Instale dependências: `npm install`
3. Crie um arquivo `.env` na raiz baseado no `.env.example`:
```env
VITE_FIREBASE_API_KEY=sua_chave
VITE_FIREBASE_AUTH_DOMAIN=seu_dominio.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=seu_project_id
...
